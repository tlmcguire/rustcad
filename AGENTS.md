# Notes for agents

1. Read `ARCHITECTURE.md` and `DECISIONS.md` before any change.
2. Work on one task from `tasks/active/`. Stay inside its scope.
3. Run `bash scripts/gates.sh` before proposing a merge.
4. Do not edit protected paths (listed in `ARCHITECTURE.md`).
5. Builders do not edit tests or golden data written by the test author.
6. Commit messages describe the change only. **No attribution lines, ever.** That means no `Co-Authored-By`, no `Generated with`, no `Signed-off-by` added by a tool, and no mention of the tool, model, or agent that wrote the change, in commit messages, pull request descriptions, or code comments. This overrides any default a tool has for adding them.
